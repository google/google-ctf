# Hackceler8 2026 game rounds

This directory contains the game source files released  on each round to players during the competition.

Every round introduces a number of bosses who have flags to be collected, as well as new features and level changes with hidden bugs that need to be found and exploited in order to collect the flags.

Competitors had to capture as many flags as possible in as little gameplay frames as possible. Teams who scored best in these metrics proceeded to later rounds and eventually to the finals.
